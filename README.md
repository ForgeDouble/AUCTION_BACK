## 📢 프로젝트 개요

한정판 이라는 것에 사람들의 관심이 쏠리기 시작하면서 많은 사람이 특별한 것을 찾고 있습니다

이에 따라 외국에서는 ebay 이라는 경매 사이트가 성황리를 이루고 있지만 국내에서는 전체적인 경매 사이트가 존재하지 않습니다.

국내 유저만을 위한 국내의 경매 사이트를 제공드리는 것을 목표로 하고 있습니다.
